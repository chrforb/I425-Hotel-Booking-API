# I425 Hotel Booking API

## Setup

1. Clone the repository.
2. Place it in:

C:\xampp\htdocs\I425\courseProj

3. Run:

composer install

4. Import the provided hotel_booking_system.sql database.

5. Start Apache and MySQL.

## Authentication

The API supports:

- Custom Header
- Basic Authentication
- Bearer Token
- JWT Authentication

## Testing

Import the included Postman collection to test all endpoints.
